# Website

This is my personal website and blog, built with [Hugo](https://gohugo.io/) and the [Tufte CSS](https://edwardtufte.github.io/tufte-css/) theme.

## Credits

- **[Tufte CSS](https://edwardtufte.github.io/tufte-css/)** the CSS framework this site is built on, created by [Dave Liepmann](https://github.com/daveliepmann) and inspired by [Edward Tufte](https://github.com/edwardtufte)'s handouts.
- **[Lume Tufte theme](https://github.com/ethmarks/lume_tufte)** the Hugo port by [Ethan Marks](https://github.com/ethmarks), adapted from the original Lume theme.
- **[ET Book](https://github.com/edwardtufte/et-book)** the font used throughout the site.
